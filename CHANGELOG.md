# 0.1.0

Initial local background logger, single-owner Mercury broker, SQLite summaries/events,
Windows service host, standalone desktop plots, and simulated integration tests.

## Live display refinement

Dark desktop theme; 1.8-pixel data curves; persistent per-channel and group visibility;
linked dotted hover guides and timestamped numeric inspection; collision-free temperature
log ticks; system-status tab; integrated HTML user manual with startup and client migration examples.

## Publication

Published vti-control as a public barreralab repository. Driver communication fixes
are committed separately and proposed in BarreraLabDrivers draft PR #4 against serial_comms.
